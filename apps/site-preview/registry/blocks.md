# PageSpec block registry (LLM reference)

Use only these `type` values on blocks: `hero`, `featureGrid`, `cta`, `footer`, `logoStrip`, `testimonial`, `richText`, `cardGrid`.

| type | Purpose |
|------|---------|
| hero | Full-width hero with optional image, title, CTAs |
| featureGrid | Icon + title grid (2–4 columns) |
| cta | Mid-page call-to-action band |
| footer | Brand + link columns + legal |
| logoStrip | Partner labels as badges |
| testimonial | Quote + author |
| richText | Plain paragraphs (no HTML) |
| cardGrid | Cards with optional image + CTA |

See package `@audion/page-spec` Zod schema for exact fields. Version: **1**.
